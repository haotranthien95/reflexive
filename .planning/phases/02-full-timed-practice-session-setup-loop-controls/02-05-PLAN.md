<objective>
Close the session's control surface and its lifecycle: the app-bar Stop with its single
confirmation dialog, the back-gesture interception that routes into that same dialog, a
wakelock held for the whole session, and interruption handling that finalizes and commits an
in-flight answer before parking the session paused.

Purpose: CTRL-02 and CTRL-03 make ending a session early deliberate and lossless. D-29, D-30
and D-31 make the session survive the real world - a back swipe, an OS screen timeout, and an
answered phone call. Each of these is a way the loop visibly breaks without this plan.

Output: exactly one early-exit path, exactly one confirmation dialog, exactly one interruption
handler, and a documented dependency addition that costs the release build no new permission.
</objective>
