**The permission audit (D-39, required).** Run `flutter build apk --release`, then locate the merged
release manifest under `build/app/intermediates/merged_manifest/release/` (the exact subdirectory
varies by Android Gradle Plugin version, so find it rather than assuming a path) and extract the
complete set of `android.permission.*` entries it declares. The expected set is exactly two:
microphone capture, which `package:record` has required since Phase 1, and network access, which the
Firestore dependency contributes transitively. Anything else — an analytics, advertising-ID, location
or account permission — is a surprise transitive grant from the Firebase dependency graph and must be
reported rather than accepted; if one appears, record which dependency contributes it before deciding
anything. This is the same inspection Phase 2 ran against the merged manifest rather than the source
manifest, and it is deliberately not automated as a test because it needs a release build artifact.

**The offline claim (D-36).** With the app freshly installed and the device online, open Setup and let
the topics load, then start and complete a short session so both reads have been served. Put the
device in airplane mode, force-stop and relaunch the app, and confirm the topics still appear and a
session still starts and runs to completion from the SDK cache. Then clear the app's data (an empty
cache, standing in for a first-run offline device), relaunch still offline, and confirm the topics card
shows the could-not-load state with its retry button — NOT the empty state. That last check is the
phase's sharpest correctness detail: a cache-served zero-document read must never read as "your
questions are gone".

**The long-text backstops.** Set the OS text size to its maximum. On Setup, confirm the long seeded

mode plus a cleared cache), and confirm the footer grows by shrinking the scroll area above with no
overflow banding and the button still fully visible at its full height. Start a session containing the
long seeded prompt and confirm it renders un-clipped in the question card in the reading, recording
and paused states.

**The malformed-document backstops.** Confirm the two deliberately malformed seeded documents produce
neither a blank checkbox row on Setup nor a blank prompt during a session, and that each skip appears

**The zero-result path.** Select only the seeded topic that has no questions at the top level and tap

that every topic, the level and all three slider values are exactly as they were.
