Write the FIRST FIVE topics in this task, in this order, using these subject strings

For each of those five subjects, write **ten questions at each of the six CEFR levels**
`A1`, `A2`, `B1`, `B2`, `C1`, `C2` — 60 rows per topic, 300 rows in this task. Group the
rows topic by topic and, within a topic, level by level, so a human reading the file can
find a cell. Full coverage is the point: every checkbox-plus-level combination the user can
pick must return questions on a fresh bank, and ten per cell means a 20-question
single-topic session cycles twice rather than four times.

Content rules, all of which the file must satisfy on its own terms:
- Every question is answerable OUT LOUD in a few sentences. No written-essay prompts, no
  yes/no trivia, no questions with a single correct factual answer.
- Level-appropriate vocabulary and grammar, per the per-level rules in the generation
  prompt.
- Every question is unique across the whole file — not merely within its cell. The
  content/subject/level triple must be unique, and near-duplicate phrasings within a topic
  should be avoided so a session does not feel repetitive.
- **Answerable by anyone.** A question must not require the learner to disclose a health
  condition, their income, their religion, their immigration status or their sexual
  orientation in order to answer it, and must not presume a particular family shape, income
  level, physical ability or nationality. Prefer openings the learner can answer about
  someone or something else when a topic edges toward the personal — for example, ask about
  what makes a workplace good rather than what the learner earns, or about how people in
  general stay active rather than about the learner's own medical history.
- Plain ASCII apostrophes and no embedded newlines, so the file is trivially valid JSON and
  the rows render as single lines in the app's skip list if any ever needs to.
